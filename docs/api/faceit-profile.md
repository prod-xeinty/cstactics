# Профиль FACEIT текущего игрока

`GET /api/faceit/me` доступен только после входа через Steam. Сервер берёт Steam ID из сессии и обращается к FACEIT Data API с секретом `FACEIT_API_KEY`. Клиенту ключ не передаётся. UI для модалки после входа (#13) может вызвать этот маршрут один раз.

Ответы всегда с `Cache-Control: no-store`:

- `200` — `{ "profile": { "status": "ready", "level": 8, "elo": 2040, "band": "high" }, "source": "FACEIT" }`;
- `200` — `{ "profile": { "status": "not_found", "band": "none" }, "source": "FACEIT" }`, если FACEIT вернул 404 или у игрока нет CS2;
- `401` — нет сессии Steam;
- `429` — превышен внутренний лимит запросов профиля (12 за час на аккаунт);
- `503` — ключ не задан, FACEIT недоступен или вернул неполные данные. Это не означает, что профиля нет.

Уровень и эло не записываются в D1. Так соблюдаем [решение по условиям FACEIT](../../AGENTS.md#13-журнал-решений), пока не подтверждён допустимый срок кеширования ответа API. При выводе данных в UI указывать источник FACEIT; дополнительные требования к атрибуции ещё уточняются (#19).
