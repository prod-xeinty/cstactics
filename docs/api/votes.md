# Голоса и оценки тактик

`GET /api/tactics/{id}/votes` публично отдаёт `{ "ratings": { "low": ..., "mid": ..., "high": ..., "none": ... } }` только для опубликованной тактики. Каждая шкала содержит `votes`, `works` и `easy`. Средние `works` и `easy` равны `null`, пока голосов меньше пяти. После пяти голосов средние округляются до одного знака.

`POST /api/tactics/{id}/votes` принимает JSON `{ "works": 1..5, "easy": 1..5 }`. Нужны Steam-сессия, заголовок `Origin` своего сайта и `x-csrf-token`. Последний приходит в `GET /api/auth/me` как `csrfToken` для вошедшего игрока. Один игрок может изменить свой голос; дубликата не будет. Ответ содержит текущую `band` и обновлённые `ratings`. Частоту записи ограничиваем 20 запросами в час на игрока.

Если FACEIT возвращает 404 или профиль без CS2, голос идёт в отдельную шкалу `none`. Если FACEIT недоступен, POST возвращает `503` и не меняет голос. `401` — нет сессии, `403` — неверный Origin/CSRF, `404` — тактика не опубликована или отсутствует, `400` — некорректные оценки, `429` — превышен лимит.

Cron раз в 6 часов проверяет до 10 игроков с голосами, у которых подошёл срок обновления группы (три дня после предыдущей успешной проверки). При ошибке FACEIT повторяет попытку через час. Уровень и эло не сохраняются в D1; `faceit_profiles` используется только для времени следующей проверки. Голоса и агрегаты `rating_stats` пересчитываются в одной транзакции D1.
