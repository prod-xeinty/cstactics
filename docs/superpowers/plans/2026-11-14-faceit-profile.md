# FACEIT-профиль по Steam ID (#10)

## Решение

Серверный маршрут `GET /api/faceit/me` берёт Steam ID только из текущей сессии и запрашивает FACEIT Data API. Ответ содержит уровень, эло и шкалу либо состояние `not_found`. Ошибка FACEIT или отсутствующий ключ дают `503`, а не ложное «без FACEIT». Ответ и данные FACEIT не записываются в D1 и отправляются с `Cache-Control: no-store`: срок кеширования ответа API пока не подтверждён. UI воспользуется маршрутом в #13.

## Файлы

- `src/faceit/client.ts` — запрос, проверка данных и вычисление шкалы.
- `src/app/api/faceit/me/route.ts` — сессия, лимит запросов, безопасный ответ.
- `src/platform/types.ts` — имя серверного секрета.
- `src/security/rate-limit.ts` — лимит для запроса профиля.
- `tests/faceit-client.test.ts`, `tests/faceit-route.test.ts` — проверка поведения.
