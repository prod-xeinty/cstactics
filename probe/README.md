# Замер доступности из РФ (задача #20)

Проверяем, дойдёт ли до игроков из России сайт на Cloudflare. С июня 2025 года ряд российских провайдеров обрывают соединения с Cloudflare примерно после 16 КБ ([Хабр](https://habr.com/ru/news/922532/)). Нам нужны **свои измерения**: что творится сейчас и на каких провайдерах.

Это отдельная страница для замера. Она не часть сайта и не содержит ни секретов, ни пользовательских данных.

## Что внутри

| Файл | Зачем |
|---|---|
| `public/index.html`, `public/probe.js` | Страница с кнопкой «Запустить замер». Качает файлы 1 КБ, 20 КБ, 100 КБ и 1 МБ по 3 раза каждый и показывает, сколько байт дошло и за какое время |
| `public/p/*.bin` | Файлы со случайными данными (не сжимаются, поэтому размер честный) |
| `public/_headers` | Защитные заголовки (CSP, nosniff) и запрет кеша для файлов замера |
| `wrangler.jsonc` | Конфиг выкладки на Cloudflare Workers (только статика) |

## Как выложить

Нужен аккаунт Cloudflare (бесплатного достаточно) и Node.js.

```bash
cd probe
npx wrangler login      # один раз, откроется браузер
npx wrangler deploy     # выложит на https://kollgg-probe.<ваш-аккаунт>.workers.dev
```

Адрес `*.workers.dev` может блокироваться отдельно от самой Cloudflare. Когда у нас появится свой домен (#2), стоит повторить замер и на нём.

## Контроль: те же файлы НЕ на Cloudflare

Без контроля непонятно, виновата ли Cloudflare или просто плохой интернет у человека. Выложите папку `public/` ещё на один хостинг не за Cloudflare, например GitHub Pages или российский хостинг. Пусть каждый участник замера пройдёт тест на **обоих** адресах, подряд, с одного и того же подключения.

## Как проводить замер

1. Попросите 5–10 человек открыть ссылку и нажать «Запустить замер».
2. Лучше разные подключения: МТС, Билайн, Ростелеком, МегаФон; мобильный и домашний интернет; Wi-Fi и сотовая сеть. VPN выключить.
3. Каждый нажимает «Скопировать результат» и присылает текст вам.
4. Заносите результаты в таблицу ниже и в задачу #20.

## Как читать результат

- **Всё скачалось** на обоих адресах: у этого человека проблемы нет.
- **На Cloudflare обрывается, на контроле нет**, и обрыв начинается с файла 20 КБ и больше (1 КБ проходит): картина ровно та, о которой писала Cloudflare. На этом провайдере сайт за Cloudflare не откроется нормально.
- **Обрывается везде:** проблема в подключении человека, такой результат не засчитываем.
- **Результат прыгает** между попытками: провайдер ограничивает нестабильно, это тоже плохой знак, и стоит повторить в другое время суток.

Один человек и один замер ничего не доказывают. Решение принимаем по общей картине: сколько провайдеров из опрошенных нормально открывают Cloudflare. Чем больше аудитория из проблемных провайдеров, тем сильнее довод в пользу российского хостинга (см. #1).
